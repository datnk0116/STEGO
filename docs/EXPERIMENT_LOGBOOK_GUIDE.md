# Experimental logbook — fill only from actual work

This file is a record template. Do not backfill estimated hours or invent observations.

| Date | Start time | End time | Duration (hours) | Task / hypothesis | Command or action | Observed result / evidence path | Next action |
|---|---|---|---:|---|---|---|---|
| YYYY-MM-DD | HH:MM | HH:MM | | | | | |

## Per-session reflection

- What was the hypothesis before the experiment?
- What exact output supported or rejected it?
- What changed in the implementation or experimental design?
- What remains uncertain?
- Which result file, command log, or commit supports the entry?

## Evidence integrity

- Record the commit SHA and environment for each final verification run.
- Keep original artifacts under `data/` unchanged.
- Store transformed data and results under `results/`.
- Distinguish synthetic test data from official challenge artifacts.
- Never claim a test, run, screenshot, or duration that was not personally performed.
